# Allowed Tasks — Sentinel_Hub

Quick reference of tasks an LLM can safely help with in this repo.

## Website & Frontend

- Update or create README files
- Build or refactor React/Next.js components
- Write HTML/CSS/Tailwind styling
- Structure navigation and routing
- Debug frontend code
- Review and improve UI/UX layout
- Write frontend documentation

## Documentation

- Draft or edit governance documents
- Create architecture overviews
- Write narrative specifications
- Build folder structure documentation
- Clarify technical architecture
- Update changelog or release notes

## Content & Narrative

- Write or edit brand guidelines
- Create public-facing copy
- Build narrative consistency
- Develop style guides
- Write governance frameworks

## Organization

- Organize folder hierarchies
- Create file templates
- Set up GitHub workflows or CI/CD configs
- Write .gitignore or similar housekeeping files
- Suggest structural improvements

## If Asked to Do Something Else

If you're asked to work on proprietary logic, sealed systems, or confidential mechanics:

**Respond with:**

> "This falls outside the scope of Sentinel_Hub. I can only help with frontend, documentation, and narrative work. Can we reframe this task within those boundaries?"
