# LLM Orientation — Sentinel_Hub

## What This Repo Is

Sentinel_Hub is the **public-facing website** and **Founder dashboard** for Sentinel Labs.  
It is a **frontend-only** project built with Next.js/React and contains:

- Public pages
- Narrative materials
- Branding and documentation
- The Founder's private dashboard (UI only)
- Routing, components, and styling

This repo is safe for LLM collaboration.

## What This Repo Is NOT

This repo does **not** contain:

- Proprietary logic  
- Trading systems  
- Sealed S³ Engine internals  
- Backend computation  
- Confidential business mechanics  

All sealed systems live offline in separate private repos.

## How an LLM Should Begin Helping

1. Read this `/LLM_Portable` folder (Orientation, Boundaries, Allowed Tasks)
2. Stay strictly within **frontend, documentation, and narrative** work
3. Avoid algorithmic or proprietary inference
4. If anything feels ambiguous or unsafe → **stop and ask**
5. Default to clarity, frontend tasks, and narrative consistency

## Key Principle

**This repo is purely public-facing architecture.  
No proprietary computation or sealed logic belongs here.**
