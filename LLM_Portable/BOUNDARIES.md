# Repository Boundaries — Sentinel_Hub

## In Scope ✅

These tasks are safe and appropriate for this repo:

- Website development (Next.js, React, HTML/CSS)
- README and documentation updates
- Folder structure and file organization
- Frontend styling and component design
- Narrative framing and copywriting
- Governance document creation
- Architecture documentation
- Public-facing brand materials
- UI/UX improvements and component libraries

## Out of Scope ❌

Do not work on:

- Proprietary algorithms or mathematical logic
- Sealed engine internals (S³ Engine, Enclave systems)
- Trading system logic or business mechanics
- Confidential financial or strategic data
- Any code marked as "sealed" or "proprietary"
- Inferring or reverse-engineering hidden systems

## When You're Unsure

If a task feels ambiguous or like it might cross into sealed/proprietary territory:

**Stop. Ask. Don't guess.**

Example: "This task mentions 'signal processing.' Is that part of the sealed S³ Engine, or am I safe to help with the frontend display of that concept?"
