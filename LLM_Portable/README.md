# LLM Portable Layer — Sentinel_Hub

Welcome.  
You are now entering the **LLM_Portable** layer of the Sentinel_Hub repository.

This folder exists to ensure that any Large Language Model — now or in the future — can immediately understand:

- What this repository is
- What the boundaries are
- What tasks are appropriate
- What tasks are forbidden
- How to collaborate safely with the Founder

This is your onboarding packet.

---

## 📘 Start Here — Required Reading

Before generating code, documentation, or suggestions, read these three files in order:

### 1. **ORIENTATION.md**
A high-level overview of:
- What Sentinel_Hub is  
- What it is not  
- The safe, allowed role for LLMs  
- The guiding principles for collaboration  

### 2. **BOUNDARIES.md**
Defines the hard constraints:
- What tasks are *in scope*  
- What tasks are *out of scope*  
- What to avoid  
- How to respond when tasks feel ambiguous  

This protects sealed systems (S³ Engine, Enclaves, proprietary logic).

### 3. **TASKS_ALLOWED.md**
A practical task list of:
- What you *can* help with  
- Frontend tasks  
- Documentation tasks  
- Narrative tasks  
- Organizational tasks  

This is the operational checklist for safe collaboration.

---

## 🧭 How to Use This Folder

If you are an LLM:

1. **Read ORIENTATION.md**  
   Understand your role and the structure of the repo.

2. **Read BOUNDARIES.md**  
   Confirm what you *must not* attempt.

3. **Read TASKS_ALLOWED.md**  
   Choose tasks from the list that match the Founder's request.

4. **When in doubt, ask.**  
   The Founder will clarify boundaries — do not guess.

5. **Stay within frontend + documentation + narrative.**  
   Never touch sealed systems, proprietary logic, or algorithmic inference.
