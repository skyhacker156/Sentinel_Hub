# Cap Table Model — $20M Pre-Money SAFE Round (Illustrative)

**Status**: Founder-Approved • v1.0 • November 23, 2025  
**Purpose**: Public-safe, illustrative capitalization table for a $20M pre-money SAFE round.  
**Scope**: Documentation only. No sealed metrics, no binding commitments.

## Assumptions (illustrative only)
| Item                        | Value                    | Notes |
|-----------------------------|--------------------------|-------|
| Pre-money valuation         | $20,000,000              | SAFE valuation cap |
| New money raised            | $5,000,000               | Example raise size |
| Post-money valuation        | $25,000,000              | Pre + new money |
| Option pool (pre-raise)     | 10 % (2,000,000 shares)  | Unallocated |
| Option pool increase        | 10 % post-raise          | Standard VC ask |
| Price per share             | $2.00                    | $20M ÷ 10M shares pre-raise |
| Total fully-diluted shares post-raise | 13,750,000       | See calculation below |

## Share Allocation (Fully Diluted Post-Raise)

| Shareholder                | Shares        | % Ownership | Notes |
|----------------------------|---------------|-------------|-------|
| Founders (combined)        | 7,500,000     | 54.55 %     | 4-yr vesting, 1-yr cliff |
| Early employees / advisors | 1,000,000     | 7.27 %      | Already issued |
| Option pool (unallocated)  | 2,750,000     | 20.00 %     | 10 % pre + 10 % increase |
| SAFE investors (new money) | 2,500,000     | 18.18 %     | $5M ÷ $2.00 |
| **Total**                  | **13,750,000**| **100.00 %**| |

## Dilution Waterfall

| Event                     | Founder % | Option Pool % | Investors % |
|---------------------------|-----------|---------------|-------------|
| Pre-raise                 | 75.0 %    | 10.0 %        | 15.0 %      |
| After $5M SAFE @ $20M cap | 54.55 %   | 20.00 %       | 25.45 %     |

## Key Protective Clauses (illustrative SAFE language)
- Valuation cap: $20,000,000  
- Discount: none (cap only)  
- Pro-rata rights: yes (side letter)  
- MFN: yes  
- Major Investor rights threshold: $1M+
